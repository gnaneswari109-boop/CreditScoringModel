# Assets Directory

This directory stores generated evaluation charts and visualizations.

After running `python backend/train.py`, the following charts are generated:

- `class_distribution.png` - Distribution of creditworthy vs high-risk applicants
- `correlation_heatmap.png` - Feature correlation heatmap
- `roc_curve.png` - ROC curve comparison across all models
- `feature_importance.png` - Feature importance from the best model
- `confusion_matrix_*.png` - Confusion matrices for each model
- `accuracy_comparison.png` - Bar chart comparing all metrics
- `learning_curve.png` - Learning curve for the best model
- `prediction_probability.png` - Prediction probability distribution
